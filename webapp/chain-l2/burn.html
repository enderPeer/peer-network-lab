Burn bitcoin, earn standing

You send. Everything after that is automatic: this page watches the chain, waits for confirmations, and files the claim with the network for you.

The PIN is your network credential, sent only to your own host to file the claim. It is never stored and never touches Bitcoin. 2,000 sat is about 20 units of reserve — roughly 380 acts at the current θ.

Send exactly sat to the dead address

This output pays a script that can never be satisfied — a P2WSH commitment to OP_RETURN. There is no key and there never was, so the coins are destroyed by arithmetic rather than by trust. Nobody can spend them, including the network, including you.
