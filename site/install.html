Put the app on your phone.

No store, no account, no gatekeeper. Ender Net installs straight from this page — in the European Union and everywhere else — and what installs is the same open-source page you can read before you trust it.

You are reading this from inside the installed app — nothing more to do here.

The one-minute way

  1. Open this page in Safari.
  2. Tap the Share button at the bottom of the screen (on iPad: top right, next to the address bar).
  3. Scroll down and choose Add to Home Screen , then Add.

That is the whole install. The icon appears on your home screen and opens full-screen with no browser around it — Safari simply has no install button, so the Share sheet is where Apple put it.

Or download the install file

Prefer a real download? This file places the same icon for you. It is 5 KB of XML you can read below — one instruction, no settings touched, removable any time.

Why is this not in the App Store?

Because there is no company behind this, and it does not need one. Apple does let native apps be downloaded from a developer's own website in the EU now — but only for paid, Apple-approved developer organizations clearing steep eligibility bars, and even the EU's alternative app stores require a paid Apple subscription and Apple's signature on every app. The path used here is the one open to everyone: a web app installed straight from the page. Apple supports it in the EU — it tried to switch this off in 2024 and reversed under pressure — and everywhere else, and what you get is a real app on your home screen: full-screen, signed in, and once it has run online once, working with no connection at all.

Install

If your browser offers an install banner or an Install app entry, that is the fastest way. Otherwise:

  1. Open this page in Chrome (or any browser — Firefox works too).
  2. Open the ⋮ menu in the top corner.
  3. Choose Add to Home screen or Install app, then confirm.

The icon lands on your home screen and opens full-screen, like any installed app.

On a computer

  1. Open the app in Chrome or Edge.
  2. Click the install icon at the right end of the address bar — it says Install Ender Net.

Safari on a Mac installs it too, from the menu bar: File → Add to Dock. Firefox on the desktop does not install web apps — the site still works there as a normal page. And if it is your phone you wanted: open enderpeer.github.io/peer-network-lab/install.html there and this page will show the right steps.

What you get

The same network, wearing an app: it opens full-screen from its own icon, keeps you signed in, and — once it has run online once — still opens with no connection at all: offline it runs your own private copy of the network in your browser instead of showing an error page. It updates itself on the next load, costs nothing, and uninstalls like any app.

Installing changes nothing about your data: there is no tracking, no cookies and no analytics on this page or in the app, and nothing you write leaves your device until you choose to post to the shared network. One caveat, stated plainly: to aim the download button, this page does check once per visit whether the shared host is awake — a plain read, stored nowhere.
